# 权限边界

访问平台先由会话身份决定，群内写操作再由群权限决定。平台仍是账号、图库和任务访问权限的最终执行方。

| 使用场景 | 共享平台账号 | 个人平台账号 |
| --- | --- | --- |
| 白名单群聊 | 可用；默认仅管理员可写 | 可用；默认仅管理员可写 |
| 白名单私聊 | 可用，可执行平台允许的写操作 | 可用 |
| 白名单以外 | 禁止使用共享会话 | 已绑定个人会话可用 |
| 未配置白名单 | 全部禁止共享会话 | 不受共享白名单限制 |

## 白名单配置

WebUI 配置 `shared_session_whitelist`，或环境变量 `BILI_PLATFORM_SHARED_SESSION_WHITELIST`，填写 AstrBot 的完整 `unified_msg_origin`，以逗号或换行分隔，精确匹配。请从自己的 AstrBot 会话信息中复制，勿只填群号或用户号。群聊标识与私聊标识分别授权，不支持通配符。配置卡片优先于环境变量，显式空值表示禁用。

管理员身份不会绕过白名单。移除会话后，命令、LLM 工具、客户端缓存读取和该会话的结果通知均禁止使用共享身份。检查发生在操作入口，已开始的网络请求不会被中途撤回。

## 账号与任务

已绑定个人账号优先于自动引导的共享账号。个人账号可由服务器 CLI 绑定，密码登录默认关闭且只允许私聊；不要经模型传递密码或 sid。

共享会话会持久记录来源；历史记录若 sid 与当前共享 sid 一致也按共享处理。若旧共享 sid 已更换、历史记录又没有来源标记，管理员应在开放机器人前检查并清理旧会话。同一 sid 即使由个人绑定，也按共享身份限制。

任务操作通过当前平台会话列出的任务 ID 检查范围。共享账号的授权用户能操作同一平台身份可见的任务，当前没有按 QQ 创建者细分任务权限。插件不额外提供平台之外的账号或任务 ACL。

## 群内写权限

`group_write_admin_only` 默认开启。上传、导入、创建、编辑、取消、立即发布、重试和删除等平台写操作检查 AstrBot `is_admin()`，或群消息的 `owner/admin` 角色。关闭此配置会允许群成员执行写操作，但仍受共享会话白名单约束。

## 当前限制

- 会话、草稿、预设和选图按发送者 ID 保存，同一用户跨群与私聊共用；尚未按平台实例或群会话进一步隔离。
- 个人账号可以在群中使用，其查询结果对群成员可见。不要在不适合公开信息的会话中查询。
- 通知发到用户最近使用 `/bd` 的合规会话，共享身份通知另查白名单；不是按任务创建会话固定投递。
- 已保存的共享会话不会因为修改配置里的 sid 自动轮换，管理员需清理旧会话后重新绑定。
